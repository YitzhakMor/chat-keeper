# שומר השיחות

אפליקציית אינטרנט לשמירה ולצפייה בשיחות וואטסאפ. טוענים קובץ ייצוא של וואטסאפ (ZIP או TXT), והשיחה מוצגת כמו באפליקציה: בועות, תאריכים, תמונות, הקלטות, סרטונים, חיפוש ותצוגת מדיה מרוכזת. אפשר לשמור כמה שיחות ולראות אותן ברשימה, וכל שיחה אפשר לשמור גם כקובץ HTML עצמאי שנפתח בכל דפדפן.

**פרטיות:** השיחות לא נשלחות לשום שרת. הן נשמרות רק בדפדפן במכשיר של המשתמש, והמאגר הזה מכיל רק את קוד האפליקציה.

**התקנה בטלפון:** פותחים את הכתובת בכרום, ובתפריט בוחרים "הוספה למסך הבית" או "התקנת אפליקציה". באנדרואיד האפליקציה המותקנת מופיעה גם ברשימת השיתוף, כך שאפשר לשתף אליה שיחה ישירות מתוך "ייצוא צ׳אט" בוואטסאפ.

**גיבוי:** השיחות שברשימה נשמרות בדפדפן בלבד. אם מנקים את נתוני הדפדפן או מחליפים מכשיר, הן נמחקות. לכן כדאי לשמור כל שיחה גם כקובץ שימור ולגבות אותו, למשל ב-Google Drive. כדי לשחזר שיחה, טוענים את קובץ השימור בחזרה לאפליקציה.

קבצים: `index.html` (האפליקציה), `sw.js` (עבודה בלי אינטרנט וקבלת שיתופים), `manifest.webmanifest`, אייקונים.
